# Currency Converter

**Автор:** Жукова Дарья
**Курс:** Итоговая аттестация по GUI-разработке

## Описание приложения

Графическое приложение для конвертации валют с использованием внешнего API и сохранением истории операций в JSON.

## Требования к запуску

- Python 3.8+
- Установленные зависимости (см. requirements.txt)
- API-ключ для exchangerate-api.com

# Currency Converter

**Автор:** Жукова Дарья
**Курс:** Итоговая аттестация по GUI-разработке

## Описание приложения

Графическое приложение для конвертации валют с использованием внешнего API и сохранением истории операций в JSON.

## Требования к запуску

- Python 3.8+
- Установленные зависимости (см. requirements.txt)
- API-ключ для exchangerate-api.com

## Установка зависимостей

## Как получить API-ключ

1. Зарегистрируйтесь на exchangerate-api.com.
2. Получите бесплатный ключ.
3. Вставьте его в переменную API_KEY в файле converter.py.

## Запуск приложения

## Примеры использования

1. Выберите валюты "Из" и "В".
2. Введите сумму (например, 100).
3. Нажмите "Конвертировать".
4. Результат появится под кнопкой.
5. История операций сохраняется в history.json и отображается в таблице.
